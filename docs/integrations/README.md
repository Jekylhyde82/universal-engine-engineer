## Governing rule
PROOF BEFORE CLAIM. EVIDENCE BEFORE CONFIDENCE. VERIFICATION BEFORE COMPLETION.

A source being listed, evaluated, or approved for a trial does not mean it is installed, integrated, secure, or operational.
