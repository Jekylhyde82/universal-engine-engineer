3 · Evaluation rules

Discovery does not execute code. Do not install, import, run or grant credentials to a candidate from this tool. Licence, provenance, security, compatibility, resource fit and proof-of-capability checks must happen before any integration decision.
G0 · Source identityCanonical repository, owner and pinned commit/release.
G1 · Licence & provenanceRoot/nested licences, dependencies, assets and distribution terms.
G2 · Maintenance & compatibilityRelease health, runtime support, API stability and advisories.
G3 · Security & governanceThreat model, least privilege, sandbox, network and secrets.
G4 · Resource & deploymentCPU, RAM, storage, latency, hosting and offline behavior.
G5 · Proof of capabilityIsolated reproducible tests, acceptance criteria and negative tests.
G6 · Integration approvalHuman approval, narrow adapter, replaceability and rollback.
G7 · Operational verificationDeployed identity, independent review and operational evidence.

Popularity and stars are context only, not a quality score. Missing evidence is NOT_ASSESSED, never a silent pass.
